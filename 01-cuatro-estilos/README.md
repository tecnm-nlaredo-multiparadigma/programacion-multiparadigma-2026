# Un algoritmo, cuatro estilos

```bash
npm start
```

O directo, sin npm: `node src/comparar.js`

Los cuatro imprimen `$2,191.15`. Ese es el punto: **el resultado no distingue paradigmas.**

Preguntas para la sesion, en orden:

1. Si manana entra una regla nueva (recargo por aduana), ¿en cual de los cuatro
   la agregas tocando menos codigo? ¿Y en cual te da mas miedo tocar?
2. `E4` pesa exactamente 1000 kg, que es el umbral. Localiza en cada version
   la linea que decide si paga recargo. ¿En cual la encontraste mas rapido?
3. En el estilo declarativo las reglas son un arreglo. ¿Que se gana? ¿Que se pierde?
4. Ninguno de los cuatro tiene pruebas. ¿Cual te costaria mas trabajo probar?

> El estilo concurrente no aparece aqui a proposito: la concurrencia no se aprecia
> en un calculo sobre una lista de cuatro elementos. Hace falta que dos cosas pasen
> a la vez. Llega en la unidad 5.
