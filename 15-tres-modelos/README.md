# Taller 9 Elegir el modelo correcto

**Entrega:** jueves 3 de diciembre, 23:59. [Calendario de cierre](../CIERRE-TERCER-PARCIAL.md).

Compara tres formas de resolver un mismo requerimiento del cotizador: funciones puras con datos inmutables, reglas declarativas y procesos concurrentes. Usa dos escenarios: agregar un recargo y procesar mil embarques conservando el orden de los rechazos.

Para cada escenario, elige un enfoque, justifica tu decisión y describe una limitación. Incluye un ejemplo breve de tu repositorio. Entrega `talleres/01-dic/<control>/respuestas.md`. Tu entrega es individual.
